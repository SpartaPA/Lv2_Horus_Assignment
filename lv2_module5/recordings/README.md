## 재생 명령

**실제 모터 출력을 비활성한 상태로** 재생한다.

입력 재처리 — bag 영상만 검출기로 전달, 저장된 `/target`과 섞지 않도록 remap:

    # ros2 bag play ... --remap ...

결과 재분석 — 저장된 목표 · 상태 · 명령으로 지표 재계산:

    #

시간 기준이 필요하면 `--clock` + 관련 노드의 `use_sim_time`을 함께 적용한다. bag 시각과 현재 벽시계를 섞어 타임아웃 · 지연을 계산하지 않는다.
